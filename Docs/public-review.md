# 공개 범위 점검 결과

점검일: 2026.10.31

## 공개 대상

- MES 상태·장애 모델과 회로 차단, 변환 오류 정책, 통화 검증의 핵심 코드 발췌·일반화.
- 공개 설명을 위한 모의 실행 UI·설정 관리·상태 로그·테스트.
- 상대 폴더 이름과 가상의 통화 매핑만 담은 예제 설정.

## 제외 대상

- 실제 서버 주소·PC 경로·DB 연결 문자열·사용자·비밀번호·API 키.
- 회사·고객명, 현장 파일·검사 샘플·로그·스크린샷·DB 파일.
- 회사 전용 DLL, 원래 프로그램 EXE, 패키지·캐시·디자이너 사용자 설정.
- 원본 저장소의 Git 이력·브랜치·태그. 원본 저장소는 수정하지 않았습니다.

## 적용한 변경

- 고정 사내 통화 번호를 설정 주입으로 변경했습니다.
- 공개 실행 경로는 운영 경로를 복제하지 않고 실행 환경에서 구성합니다.
- 입력 경로 탈출·절대 경로, 설정 범위, 미등록·중복 통화를 검사합니다.
- 로그는 원문을 버리고 고정 코드만 기록합니다. 경로·계정·예외 원문을 출력하지 않습니다.
- 바이너리·사용자 설정·로그는 Git 제외 규칙으로 관리합니다.

## 검증과 한계

- .NET Framework 4.5 참조 어셈블리로 핵심·WinForms·테스트 빌드, 경고 없음.
- 공개 샘플의 정상·오류·권한·잠금·복구·동시성·설정·로그 시험 35개 통과.
- 공개 파일 목록과 본문을 대상으로 비밀정보 형태·내부 주소·사용자 절대 경로·고객 식별 문자열을 점검했습니다.
- 알려진 식별자와 패턴에 대한 점검입니다. 이 결과를 모든 형태의 민감정보 탐지에 대한 보증으로 사용하지 않습니다.
- 외부 시스템 접속·현장 통합 시험은 수행하지 않았습니다.
- Visual Studio 2015 디자이너에서 직접 여는 검증은 수행하지 않았습니다. 화면 분리·Designer 프로젝트 메타데이터·이벤트 연결은 소스와 WinForms 빌드로 확인했습니다.
